# Vigor Momentum

A local React + Vite app for the Vigor Momentum UI.

## Prerequisites

- Node.js `>=22.13.0`

## Run locally

```bash
npm install
npm run dev
```

The app serves on `http://localhost:3000` by default.

## Build

```bash
npm run build
npm run start
```

## Notes

- This project now runs as a standard client-side React app.
- The main UI lives in the existing React component tree under `app/page.tsx` and is mounted via `src/main.tsx`.
